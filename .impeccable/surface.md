# Browser controls

Mode: Operate. User-selected light outlet panel, physical order on desktop and stacked on phones.

## Direction contract

THESIS: Make each of the four outlets identifiable and show what the strip actually confirmed.

OWN-WORLD: Cool white panel, deep slate text, restrained evergreen active controls, system UI typography, tabular readings, outlined socket symbols.

STORY: The owner sees whether the server and strip are reachable, selects an outlet, and waits for its confirmed state. Setup instructions take the place of an empty panel until a strip connects.

FIRST VIEWPORT: A compact home-network header, model and connection status, four ordered outlet modules, then a single telemetry row. All-on and all-off controls sit beside the model heading. Mobile stacks outlets and wraps actions.

FORM: User-approved outlet panel. Concept-seed was attempted but the installed launcher failed because of CRLF line endings; no seed was produced. The user's explicit layout choice governs this build.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
