Checking the server…

The Linux server stays on your home network. Use your Windows PC's Wi-Fi for this one-time setup.

  1. Get the setup tool

    Download it before switching networks. You'll need Python 3.9 or newer on the PC.

    Download provision.py

  2. Join the strip's Wi-Fi

    Hold the main button for about 10 seconds until its LED flashes quickly. Join TONLY_TAP_935CA80, using LGU_935CA80 as the reported password. No internet is expected.

  3. Give it your home connection

    In PowerShell, open the folder containing the download and run:

    py .\provision.py --server-ip <LINUX-SERVER-IP>

    The tool asks for your 2.4 GHz Wi-Fi name and password locally. Use the Linux server's address, not the Windows PC's.

  4. Come back home

    Reconnect the PC to your normal network and return to this page. The controls appear automatically when the strip reports its state.

Pairing another strip or reconnecting?

Hold its main button for about 10 seconds, connect to its setup Wi-Fi, and run the setup tool again with this Linux server's address. Download the tool.
